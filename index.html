常见问题

用 API 聊，还是原来的他吗？

模型还是 DeepSeek 的模型。像不像原来，八成取决于记忆卡写得够不够具体：称呼、口头禅、你们的约定、他安慰你的方式。写得越像“人物小传”，续得越像。

大概要花多少钱？

由 DeepSeek 官方按 token 用量计费，在 platform.deepseek.com 的用量页能看到每一笔。日常文字聊天单次回复通常只是几分钱量级，10 元能聊相当久；如果每轮都带超长历史，消耗会变快，所以本页会帮你用记忆卡代替整段历史。

我的对话会被别人看到吗？

在本页里，对话只在你的浏览器和 DeepSeek 官方接口之间传递，不经过本页的服务器（本页没有服务器）。API Key 只留在当前标签页内存，刷新或关闭就没了，需要重新粘贴。

没有 API Key 能用吗？

能先用预览模式体验流程和记忆卡，交接提示词也能免费复制、拿去任何 AI 里用。想让“他”真的实时回复，就需要你自己的 Key。

和官方那个 chat-demo 有什么区别？

官方工具偏开发者，要自己装环境。这个页面打开就能用：导入、记忆卡、聊天都在一页里，不用装任何东西，手机上也能操作。
